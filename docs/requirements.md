# AI Study Platform

## Goal

Build an AI-powered platform that helps students learn more effectively.

---

# User Stories

As a student,

- I want to create an account.
- I want to log in securely.
- I want to organize my notes by subject.
- I want AI to summarize my notes.
- I want AI to generate quizzes.
- I want flashcards.
- I want to upload PDFs.
- I want to track my study progress.
- I want to search my notes.
- I want to edit and delete notes.

---

# Core Features

- Authentication
- Dashboard
- Subjects
- Notes
- AI Summary
- Flashcards
- Quiz Generator
- Search
- Progress Tracking
